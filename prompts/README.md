# 프롬프트 카탈로그

구현, 리뷰, 장애 대응에 재사용할 프롬프트를 정리합니다.

- `0-initial-setup.md`: 요구사항과 ADR을 읽고 초기 실행 계획을 세울 때 사용합니다.
- `1-requirements-review.md`: 요구사항을 설계 결정 후보와 ADR 주제로 분해할 때 사용합니다.
- `plans/000-plan-template.md`: 계획 문서 작성용 기본 템플릿입니다.
- `plans/001-implementation-plan.md`: 현재 구현 단계에서 사용할 실행 계획입니다.

API 설계, Worker 연동 정책, 컨테이너 실행 방식, Mock Worker OpenAPI 참조 방식, 우리 서버 Swagger 노출 방식, 제출 산출물 구성이 바뀌면 위 프롬프트도 함께 갱신합니다.
